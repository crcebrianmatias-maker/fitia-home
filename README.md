# FitIA Home V5

Novedades:
- demos animadas cortas por ejercicio, listas para reemplazar por videos reales/IA;
- ciclos automáticos de 4 semanas;
- gráficos de peso, cintura, abdomen, pecho, bíceps y pierna;
- entrenador IA con contexto de perfil, mediciones, últimos entrenamientos y semana del ciclo;
- PWA instalable;
- entrenamiento guiado serie por serie;
- progresión automática.

Ejecutar:
pip install -r requirements.txt
python app.py

Abrir:
http://127.0.0.1:5000

Para usarla cómodamente en Samsung, publicarla con HTTPS.

IA opcional:
OPENAI_API_KEY
OPENAI_MODEL
